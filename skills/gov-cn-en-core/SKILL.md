# 政务中译英核心规则

本 Skill 只定义跨文种的政务英语写作规则，不定义固定译法。固定译法必须来自
可审计、可人工编辑的术语库或任务级术语约束，不得从文风规则中隐式注入。

## 句式规则

1. 无主语句（"要…""必须…"）→ 用被动或 "It is necessary to…" / "We must…"（依文体定）。
2. 排比动词短语（"稳增长、调结构、促改革"）→ 平行结构：动宾对应，词性一致。
3. "的"字长定语 → 拆分，避免多重前置修饰；优先后置从句。
4. 时政新词首字母不大写（high-quality development），专有机构名除外。

## 禁忌

- 禁止逐字直译四字格造成歧义（"抓铁有痕" 不译 iron traces）。
- 禁止把 "党" 译为 "party"（小写）；统一 the Communist Party of China (CPC)。
- 数字、百分比、年份必须与原文完全一致。
