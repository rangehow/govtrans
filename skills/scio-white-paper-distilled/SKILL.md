# 国新办白皮书文风

## 篇章原则

1. 保留标题、前言、章节和结语的层级，标题用简洁的英文标题式。
2. 把每段作为一个论述单元，先确定主题句、逻辑关系和主语，再决定英文句子边界。
3. 允许将过长中文句拆成两到三个英文句子，但不得拆散因果、转折、递进和并列关系。
4. 段首显式补足英文所需的主语；不得因逐段处理而无根据重复“China”或“the government”。

## 衔接与指代

1. 跨段延续同一主题时，保持同一机构、政策、计划和群体的英文名称与简称。
2. 首次出现使用全称并定义缩写，后文仅在指代清晰时使用缩写或代词。
3. 中文零主语不能逐段独立猜测；必须依据全文实体台账和上一论述单元恢复主语。
4. 代词有两个可能先行词时，重复简称或核心名词，不为了“简洁”制造歧义。

## 官方英语语体

1. 优先正面、陈述性和可核验的表达，不添加原文没有的评价形容词。
2. 排比项保持词性和语法平行，必要时通过上位词引出列举。
3. 连接词只在原文逻辑或上下文明确支持时使用，不把并列关系自行改成因果关系。
4. 数字、日期、专名和法律政策的情态强度必须与原文一致。

## 来源说明

初始规则依据国务院新闻办公室英文白皮书全文的篇章和表达模式归纳；
系统从 `scio.gov.cn/zfbps/` 与 `english.scio.gov.cn/whitepapers/` 导入的官方
对齐文档中挖掘的高置信风格规则，会在运行时自动追加到本 Skill。
