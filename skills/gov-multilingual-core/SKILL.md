# 多语种政务翻译通用规则

本 Skill 只定义跨语言通用的忠实性、正式语域和篇章一致性要求，不提供任何固定译法。

1. 完整翻译每个命题，不遗漏、不增译、不把上下文中的内容重复带入当前段落。
2. 数字、日期、金额、百分比、专名、缩写、法律与政策情态强度必须与源文一致。
3. 使用目标语言自然、正式、可发布的政务语域，避免保留源语言语序造成生硬表达。
4. 全文实体、称谓、缩写、时态、指代与列表结构保持一致。
5. 保留标题、章节、段落和列表层级；只能在不改变逻辑关系时调整句子边界。
6. 固定译法只来自当前语言对的术语库或任务级人工术语，不得从文风规则隐式生成。
