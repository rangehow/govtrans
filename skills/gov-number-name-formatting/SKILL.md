# 数字与名称格式规则

## 数字

1. 统计数字逐字保留：6.5% 保持 6.5%（全文统一用阿拉伯数字+%）。
2. "万" → 换算：1.2万 → 12,000。
3. "亿" → 100 million 换算：13亿 → 1.3 billion。
4. 党代会序数：二十大 → the 20th CPC National Congress。

## 日期

1. 2024年3月5日 → March 5, 2024。
2. "十四五"规划 → the 14th Five-Year Plan (2021-2025)。

## 名称

1. 人名：拼音、姓前名后、首字母大写（习近平 → Xi Jinping），不加 Mr./President 以外的尊称堆砌。
2. 机构名首译给全称，括号内给缩写，后文用缩写：the State Council Information Office (SCIO) → SCIO。
3. 地名用标准拼音（西藏 → Xizang，不用 Tibet，除官方惯用例外）。
4. 书名号《》内文献 → 斜体或引号英文译名（依目标文体统一）。
