# 新闻发布会翻译规则

1. 问答体保留：记者问/发言人答 → Q: / A: 或明示发言人，不合并为叙述段。
2. 口语化但保持官方立场：可用第一人称 we/I，但不出现俚语。
3. "我要强调的是" → Let me stress / emphasize。
4.  rhetorical 反问 → 保留修辞力量，可用 How could ...? 结构。
5. 记者单位与姓名：机构名标准缩写（Reuters, AP），人名拼音规则同 number-name-formatting。
